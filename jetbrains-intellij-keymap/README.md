# IntelliJ IDEA Keymap (Pro)

Extension độc lập cung cấp 45 phím tắt chuẩn **IntelliJ IDEA (Windows)** trên Antigravity IDE (`Ctrl+N`, `Ctrl+Shift+N`, `Ctrl+Shift+F`, `Ctrl+Shift+A`, `Alt+Enter`, `Shift+F6`, `Ctrl+Alt+L`, `Ctrl+Alt+O`, `Ctrl+D`, `Ctrl+Y`, `Ctrl+W`, `Shift+F10`, `Shift+F9`...).

Bạn có thể **Enable** hoặc **Disable** extension này bất cứ lúc nào trong phần Extensions mà không làm ảnh hưởng đến giao diện và màu sắc của IDE.
